# Trader Sentiment Analysis

## Objective
Analyze trader behavior during Fear vs Greed market sentiment.

## Tools Used
- Python
- Pandas
- Seaborn
- Matplotlib

## Workflow
1. Data Cleaning
2. Date Conversion
3. Dataset Merging
4. Visualization
5. Insight Generation

## Key Findings
- Higher profits during Greed
- Larger losses during Fear
- Traders preferred LONG positions during Greed

## Recommendations
- Use sentiment-aware strategies
